# 回滚说明

## GitHub 网页回滚

1. 打开仓库 Commits。
2. 找到错误的后台提交。
3. 使用 Revert（或创建反向提交的 Pull Request）。
4. 将回滚提交进入 `main`；Cloudflare 自动重新部署。

不要用强制推送覆盖历史。图片使用唯一文件名，回滚数据后旧引用仍可恢复。

## 命令行回滚

在确认目标 commit 后执行 `git revert <commit-sha>`，检查改动，再推送正常的 revert commit。若只是隐藏错误产品，后台“隐藏”通常比完整回滚更安全。

## 恢复迁移前数据

`backups/pre-admin-2026-07-28/` 保存 83 个产品和分类快照。恢复前先创建新分支，比较当前数据，避免覆盖后台后来新增的内容。

## 图片清理

删除产品不会删图片。需要清理 `public/assets/uploads` 时，先用产品 JSON 搜索引用并生成清单，确认没有产品/详情图使用后再单独提交；系统不会自动执行不可恢复的批量删除。
