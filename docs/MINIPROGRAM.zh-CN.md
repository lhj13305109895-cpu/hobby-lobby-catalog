# 微信原生小程序

源码：`src/miniprogram/`。生成目录：`miniprogram/`（自动生成，不提交 Git）。

执行 `npm run build:miniprogram` 同步当前网站商品、系列、容量及装箱量，小程序不展示或导出价格；执行 `npm run test:miniprogram` 检查目录、编号搜索、容量装箱量、选款存储和分享路径。

只在小程序上新的草稿商品追加到 `src/miniprogram/data/local-products.json`，编号接续网站和小程序已有商品；这类草稿用显式 `hybrid` 模式本地预览。默认 `website` 模式复用网站商品资料和图片路径，每款只生成一条记录。已同步商品保留本地照片源文件用于回退，但不把这些照片打进默认小程序包。

没有 npm 命令的环境可直接执行 `node scripts/build-miniprogram.mjs` 和 `node --test tests/miniprogram.test.cjs`。
