# iPhone 后台使用说明

后台地址：`https://hobby-lobby-catalog.pages.dev/admin`

## 登录

用 Safari 打开后台，点击“使用 GitHub 登录”并授权配置好的 GitHub OAuth App。只有 `ADMIN_GITHUB_LOGINS` 中的账号可以进入。会话使用 HttpOnly、Secure、SameSite Cookie，12 小时后过期；过期后重新点击 GitHub 登录即可。

## 新增产品

1. 点“＋新增产品”。如发现草稿，可选择恢复。
2. 点“选择产品主图”，从相册选择 PNG/JPG/WebP/HEIC/HEIF。
3. 需要时点“添加详情图”并多选。
4. 等待“图片处理完成”及大小对比；检查 contain 预览没有裁切。
5. 分别填写中英文名称、简介、alt、型号和容量。
6. 搜索/选择已有分类；需要新分类时点“＋新建分类”。
7. 设置新品、推荐、置顶、显示和排序。
8. 点“确认发布”一次。按钮处理期间禁用，服务端用请求 ID 防止成功请求被重复提交。
9. 状态依次显示 GitHub 已保存、Cloudflare 部署中/成功/失败。
10. 部署成功后打开前台检查中文、English、分类与图片。

正式公开时若英文名称或英文 alt 为空，后台会提醒；可取消并先保存为隐藏草稿。中文修改不会覆盖英文，反之亦然。

## 产品管理

- 顶部搜索名称、型号或 ID；可按分类筛选。
- “编辑”修改字段或更换主图；新主图使用新文件名，避免缓存旧图。
- “隐藏/显示”控制前台公开状态。
- “复制”生成新稳定 ID，默认隐藏，编辑后再发布。
- “删除”只删除产品记录，不自动删图片，避免误删共享资源。
- 排序使用数字；置顶产品优先，其后按分类和产品排序值。

## 分类管理

地址 `/admin/categories`。可搜索、新建、编辑、上移、下移、隐藏、显示、启用、停用。

分类卡显示产品数量。分类有产品时，永久删除前必须选择迁移目标；系统在一个 commit 中先迁移产品再删除分类。“待分类”受保护，不能删除。优先使用隐藏或停用。

在产品表单内新建分类时，当前字段、图片与草稿不会丢失；分类成功提交后自动加入列表并选中。

## 更换分类或主图

- 换分类：编辑产品 → 选择新分类 → 确认发布。
- 换主图：编辑产品 → 选择产品主图 → 等待处理 → 确认发布。旧图片不会被覆盖或自动删除。

## 查看保存与部署

- 后台状态栏显示 GitHub commit 短 SHA。
- GitHub 仓库 Commits 可查看完整变更。
- Cloudflare Pages → Deployments 查看对应 commit。
- Cloudflare 构建失败不会替换上一个成功的线上版本。
